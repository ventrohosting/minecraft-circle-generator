# Minecraft Kreis- und Kugel-Generator

Minecraft Kreis- und Kugel-Generator: Durchmesser eingeben, Vorlage Block für Block ansehen, Blöcke pro Reihe und Ebene ablesen. Kostenlos.

**Online nutzen:** [Minecraft Kreis- und Kugel-Generator](https://ventrohosting.com/tools/minecraft-kreis-generator) · Demo: https://ventrohosting.github.io/minecraft-circle-generator/

## Funktionen

- Kreise und Ellipsen bis 256 Blöcke, Kugeln und Kuppeln bis 128 Blöcke
- Rand geschlossen, dünn oder gefüllt, Ebene für Ebene
- Blöcke pro Reihe und Gesamtzahl mit Stacks, alles im Browser

## English

Minecraft circle and sphere generator: plan circles, ellipses, spheres and domes block by block, with blocks per row and layer. Runs entirely in the browser.

Use it online: https://ventrohosting.com/tools/minecraft-kreis-generator

## Selbst hosten

Statische Seite ohne Build-Schritt und ohne Abhängigkeiten: `index.html` und `tools.js` auf einen beliebigen Webserver legen oder GitHub Pages aktivieren. Alles läuft im Browser, es werden keine Daten gesendet.
